Instant Decoder

Upload a screenshot of an Instant Football odds board. The page reads the prices and shows what the game's own engine believes: true probabilities, house margin, expected goals and most likely scores.

This cannot beat the game. Virtual results are drawn by RNG from the same model that set these odds. Every price carries roughly a 5% house margin, so every bet has negative expected value. This tool only shows you the model honestly.

One match per line: HOME AWAY 2.10 3.65 3.33 (1 X 2). Add an Over/Under market with three more numbers: FUL BHA 2.10 3.65 3.33 2.5 1.80 2.02 (line, over, under). Start a line with # to set the league, e.g. #England.
